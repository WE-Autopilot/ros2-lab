# Luke Blommesteyn ROS2 Lab

This folder contains Luke Blommesteyn's submission for the WE Autopilot ROS2 lab.

## Project Overview

The project extends the standard turtlesim demo into a mini autonomy stack made up of three ROS2 nodes:

1. `initial_setup` - replaces the default turtle with a user-named turtle spawned at a chosen start pose.
2. `waypoint_controller` - drives the turtle toward a configurable goal using a proportional controller with velocity saturation and a goal completion publisher.
3. `pen_manager` - updates the turtle's pen colour based on the quadrant of the map and listens for the goal-complete signal to disable drawing once the target is reached.

The nodes communicate over topics/services scoped to the turtle name, making it easy to run multiple scenarios by changing parameters.

## Prerequisites

- ROS 2 Humble (or compatible) installed and sourced.
- `colcon` build tools available on your PATH.

## Workspace Layout

```
ros2_ws/
  src/
    robot_controller/   # ROS 2 package containing the nodes described above
```

> No `build`, `install`, or `log` directories are checked in. They will be generated by `colcon build`.

## Build Instructions

```bash
cd ros2_ws
colcon build
```

After the build finishes, source the generated setup script:

```bash
source install/setup.bash     # Linux/macOS
call install\setup.bat        # Windows (from a Visual Studio Developer prompt)
```

## Running the Demo

Open three terminals. Make sure each terminal has sourced the workspace's `install` setup file.

1. **Terminal 1 - turtlesim:**
   ```bash
   ros2 run turtlesim turtlesim_node
   ```

2. **Terminal 2 - initial spawn and controller:**
   ```bash
   # Optional: choose custom spawn pose or turtle name
   ros2 run robot_controller initial_setup --ros-args -p spawn_x:=5.0 -p spawn_y:=5.0 -p turtle_name:=weap_turtle

   # Drive the turtle to a goal (defaults to x=9.0, y=9.0)
   ros2 run robot_controller waypoint_controller --ros-args -p turtle_name:=weap_turtle -p target_x:=9.5 -p target_y:=9.5
   ```

3. **Terminal 3 - pen manager (runs in parallel with the controller):**
   ```bash
   ros2 run robot_controller pen_manager --ros-args -p turtle_name:=weap_turtle
   ```

## Stopping the Nodes

The `waypoint_controller` node automatically stops and publishes zero velocity once the turtle is within the goal tolerance (default: 0.4 m). All nodes can be terminated with `Ctrl+C` once you're done.

## Testing

A lightweight unit test is provided for the controller's heading helper. Run it after building:

```bash
colcon test --packages-select robot_controller
colcon test-result --verbose
```
