# ROS2 Lab
This project contains ROS 2 Python nodes for the OA:

- `hello_node.py`: prints a hello message
- `circle_publisher.py`: moves the turtle in a circle
- `pose_subscriber.py`: subscribes to turtle pose
- `celsius_publisher.py`: publishes random temperatures in Celsius
- `fahrenheit_converter.py`: converts Celsius to Fahrenheit and publishes
- `fahrenheit_logger.py`: logs received Fahrenheit temperatures
