# ROS2 Lab Submission – Zayan Khan

This folder contains my ROS2 lab work (Parts A–D) for the WE Autopilot Club.

## Contents
- `hello_node.py` – Simple ROS2 node that prints a message.
- `circle_publisher.py` – Publishes circular velocity commands to Turtlesim.
- `pose_subscriber.py` – Subscribes to the turtle’s pose and logs position.
- `wander_publisher.py` – Publishes random velocity commands to make the turtle wander.
